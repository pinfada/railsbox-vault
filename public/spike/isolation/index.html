Coût de l'isolation multi-origine sur le runtime v86

Cette page ne mesure rien d'elle-même : elle démarre le Worker runtime, lui demande de booter un guest et d'exécuter des étapes chronométrées, puis affiche son compte rendu. La même page est servie par deux serveurs — l'un nu, l'autre sous Cross-Origin-Opener-Policy: same-origin et Cross-Origin-Embedder-Policy: require-corp. La seule variable est l'en-tête. Le protocole est décrit dans docs/spikes/0041-isolation-coop-coep.md.
