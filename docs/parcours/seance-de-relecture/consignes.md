# Essayer RailsBox Vault : ce que l'on attend de vous

Merci d'avoir accepté. Cette page est pour vous. Elle tient en quelques minutes de lecture.

## À quoi sert la séance

RailsBox Vault est un logiciel qui garde vos données dans votre navigateur, sur votre appareil. Il
est encore jeune. Nous voulons savoir si **une personne qui n'est pas du métier** comprend ce qu'il
affiche et sait quoi faire, sans qu'on la guide.

**On observe le logiciel, pas vous.** Si une phrase n'est pas claire, c'est la phrase qui a un
défaut. Il n'y a pas de bonne réponse, pas de note, et pas de test de compétence.

## Ce que vous allez faire

Vous allez parcourir neuf écrans, du premier lancement jusqu'à la fin. Vous allez créer un coffre,
recopier un code sur une feuille, l'utiliser, faire une sauvegarde, puis la rouvrir. À trois
moments, la personne qui vous accompagne vous demandera de vous tromper **volontairement**, pour
voir ce que le logiciel répond. Elle vous le dira à ce moment-là.

## Ce que vous n'avez pas à savoir

Rien de technique. Vous n'avez pas à connaître l'informatique, le chiffrement ni le fonctionnement
d'un navigateur. Si un mot vous est inconnu, **dites-le** : c'est précisément ce que nous cherchons.

## Ce qu'on vous demande

- **Lisez à voix haute ce que vous pensez**, comme si vous parliez tout seul : « je crois qu'il faut
  cliquer ici », « je ne comprends pas ce mot ».
- **Faites comme vous feriez seul.** Ne cherchez pas à bien faire.
- **Dites-le quand vous hésitez**, même si vous finissez par trouver.

La personne qui vous accompagne ne répondra pas à la plupart de vos questions pendant la séance. Ce
n'est pas de l'impolitesse : elle note ce que vous cherchez. Elle répondra à la fin.

## Aucune donnée réelle

**Ne saisissez aucune donnée réelle, à aucun moment.** Pas de vrai mot de passe, pas de vrai
document, pas de vraie information personnelle. Inventez une phrase pour l'occasion, par exemple
quelques mots sans lien entre eux. Cette version est une version d'essai : elle n'est pas faite pour
garder des secrets.

Ce que vous créez pendant la séance sera effacé à la fin.

## À quoi vous attendre

- **Durée prévue : environ une heure et quart.** C'est une estimation, qui n'a pas encore été
  mesurée avec une vraie personne. Une pause est possible à tout moment.
- **Une attente d'environ deux minutes** au moment de démarrer l'application, la première fois. La
  page peut sembler figée : c'est annoncé à l'écran. Ne fermez pas l'onglet.
- Un navigateur précis : Chrome ou Edge. La personne qui vous accompagne l'aura préparé.
- Une feuille de papier et un stylo, pour recopier un code.

## Si vous êtes bloqué

- Dites simplement **« je suis bloqué »**. La personne qui vous accompagne note l'endroit, puis vous
  débloque. Être bloqué n'est pas un échec de votre part : c'est une information utile.
- Si quelque chose vous inquiète (vous avez peur d'avoir tout perdu, d'avoir cliqué sur un mauvais
  bouton), dites-le tout de suite. Rien de ce que vous faites ici n'est grave : le coffre est un
  coffre d'essai.
- Vous pouvez **arrêter à tout moment**, sans avoir à vous justifier.

## Ce que deviennent vos remarques

Elles servent à corriger le logiciel. Elles sont notées **sans votre nom**.
