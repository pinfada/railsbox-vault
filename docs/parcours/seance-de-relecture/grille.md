Pour le mainteneur. Une grille par séance, à imprimer ou à copier. **Rien n'est prérempli ni
coché.** On remplit pendant la séance, on ne reformule pas après coup. Le procédé est dans
[`conduite.md`](conduite.md) ; ce que la personne reçoit est dans [`consignes.md`](consignes.md).

Les textes de chaque écran sont ceux de [`../relecture-p2.md`](../relecture-p2.md), générée depuis
les textes servis. Cette grille ne les recopie pas : elle dit ce que la personne **doit
comprendre**.

## Comment remplir un écran

- **Compréhension** — cochez UNE case : ☐ compris sans aide · ☐ compris avec aide · ☐ bloqué. « Avec
  aide » : la personne a demandé de l'aide, ou vous avez dû intervenir. « Bloqué » : elle ne pouvait
  pas continuer sans que vous la débloquiez.
- **Temps passé** — du moment où l'écran apparaît à celui où la personne clique sur le bouton
  d'après. Pour l'attente du démarrage, notez l'attente et ce que la personne a fait pendant.
- **Verbatim** — ses mots exacts, entre guillemets. Pas votre interprétation.
- **Gravité** — cochez UNE case : ☐ 0 rien · ☐ 1 gêne (a compris seule, après un temps) · ☐ 2
  confusion (a compris avec aide) · ☐ 3 blocage, ou risque de perdre des données (n'a pas compris,
  ou a compris de travers).

## Les neuf écrans

### 1. Créer votre coffre (avec l'écran d'entrée)

**Doit comprendre** : ce qu'est « un coffre » (des données gardées sur cet appareil, protégées par
un secret) ; quel bouton choisir quand on n'a pas de sauvegarde, et lequel quand on en a une ; **les
limites de cette version** : Chrome ou Edge seulement, un premier démarrage long, un gros
téléchargement, beaucoup de mémoire, des données non sensibles seulement, une application non
signée, le hors connexion après un premier démarrage en ligne.

- Compréhension : ☐ sans aide ☐ avec aide ☐ bloqué
- Temps passé : ………
- Verbatim : ………
- Gravité : ☐ 0 ☐ 1 ☐ 2 ☐ 3
- Limites : citées spontanément, ou qui a surpris : ………
- Mot qui a arrêté ou inquiété : ………

### 2. Choisir comment l'ouvrir

**Doit comprendre** : que le coffre est créé dès le clic ; qu'il faudra retenir la phrase ; que
l'onglet peut sembler figé pendant un calcul volontairement lent, et qu'il ne faut pas le fermer ;
(passkey) qu'on peut ne pas en utiliser.

- Compréhension : ☐ sans aide ☐ avec aide ☐ bloqué
- Temps passé : ………
- Verbatim : ………
- Gravité : ☐ 0 ☐ 1 ☐ 2 ☐ 3
- A fermé ou rechargé l'onglet pendant l'attente : ☐ oui ☐ non
- Phrase choisie : ne **pas** la noter.

### 3. Recevoir et confirmer votre code de récupération

**Doit comprendre** : que le code ne s'affiche **qu'une fois** ; qu'il faut recopier le code **et**
le numéro de feuille, et ranger la feuille ailleurs que près de l'appareil ; qu'il faut ensuite
verrouiller le coffre et le rouvrir avec le code de la feuille ; que, si l'on se trompe en
recopiant, la phrase rouvre le coffre.

- A noté le numéro de feuille : ☐ oui ☐ non
