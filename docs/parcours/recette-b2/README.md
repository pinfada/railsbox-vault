# Recette QA ciblée du lot B2 (#266, #242) — 17/11/2026

Chromium (Playwright), coquille réelle sans machine virtuelle, coffre d'essai créé pour la recette
(phrase publique, aucune donnée personnelle). **Avant** : `main` `c48e5be`. **Après** : la branche
du lot. Largeurs 360 et 1280 px ; clair et sombre là où c'est pertinent. Les mesures brutes sont
dans `avant/` et `apres/` (`*.json`) ; les captures nomment le constat, la largeur et le thème.

Rejouer (depuis la racine du dépôt) : servir la coquille et l'origine applicative
(`node tools/serve.mjs --role shell --host 127.0.0.1 --port 4105 --app-origin http://localhost:4106`
et `--role app --host localhost --port 4106`), puis
`node docs/parcours/recette-b2/scripts/recette.mjs http://127.0.0.1:4105 <dossier> 360 light 1280 dark`
et `scripts/recette2.mjs http://127.0.0.1:4105 <dossier> 360 1` (le dernier argument ralentit le CPU
: `12`).

Limite : cette machine est rapide (création 0,7 s, réouverture 0,5 s) ; les durées de la recette du
03/10 (1,6 s, 11 s) ne sont pas reproduites ici.
